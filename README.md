## About me

I build ASP.NET Core APIs and gRPC microservices on the newest .NET, plus APIs in Python
and Go. I started with .NET as a trainee at GlobalLogic in 2022 and joined i4B as an intern
in 2023, where I now work as a software developer. Most of my work is backend architecture
in C#: I have written it since .NET 6. I am currently learning Blazor to build front ends
without leaving the .NET stack.

I speak English and German and I'm learning Dutch.
